## Projects

**ProcureSense AI — Smart Procurement Platform · FYP**
`React` · `Node.js` · `PostgreSQL` · `FastAPI` · `PyTorch` · `NLP` · `JWT`
Multi-tenant SaaS procurement system with RFQ management, vendor lifecycle tracking, and role-based access control (RBAC) — cutting manual procurement steps by ~50% through automated workflow execution.
AI-driven spend analysis and risk evaluation surfaced on a real-time analytics dashboard, powered by a Dockerized FastAPI microservice and PyTorch forecasting models.

**CareerCraft — AI Career Development Platform**
`MERN` · `OpenAI` · `NLP` · `Docker` · `Kubernetes` · `Tailwind CSS`
AI-powered career platform: Resume Builder with ATS scoring, Interview Simulator, Skill Gap Analysis, and a Career Roadmap Generator delivering real-time personalized recommendations.
Scalable full-stack architecture with AI-powered APIs, Dockerized services, Kubernetes orchestration, and interactive analytics dashboards.

**ShopEx — Full-Stack E-Commerce & User Management**
`Next.js` · `Express.js` · `TypeScript` · `Supabase` · `Django` · `Tailwind CSS`
E-commerce platform with multi-role authentication, Google OAuth, JWT sessions, email verification, and a role-based admin dashboard for full product and user management.
Advanced multi-attribute search and filtering, image uploads, and a responsive glassmorphism UI backed by Sequelize ORM relational schema design.

**Object Detection — South Asian Urban Traffic**
`YOLOv8m` · `PyTorch` · `OpenCV` · `Roboflow` · `CLIP` · `NumPy`
Curated a custom annotated dataset of 7 South Asian traffic classes (car, bike, bus, truck, rickshaw, van, person) — 1,000+ images across crowded intersections, occlusions, and mixed lighting.
Fine-tuned YOLOv8m with a structured training/evaluation pipeline, reaching **80% mAP@0.5**, with an inference system supporting both image and real-time video input.

**RAG for Diagnostic Reasoning on Clinical Notes**
`Python` · `LLMs` · `Vector Search` · `MIMIC-IV` · `Streamlit`
Retrieval-Augmented Generation clinical Q&A system on the MIMIC-IV dataset, enabling grounded diagnostic reasoning. Context-aware retrieval over vector embeddings feeds an LLM backend for accurate, source-grounded answers.

**NeuralStoryTeller — Image Captioning System**
`PyTorch` · `CNN-LSTM` · `ResNet50` · `Streamlit`
CNN-LSTM Seq2Seq model on a pretrained ResNet50 encoder. Greedy and Beam Search decoding with BLEU-4 evaluation, packaged as an interactive Streamlit demo.
